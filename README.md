# 📚 Biblioteca de Libros de Programación

Colección de 12 libros de programación en español, escritos como capítulos individuales en formato Markdown. Cada libro cubre una tecnología o concepto desde los fundamentos hasta temas avanzados y producción.

---

## 📖 Libros Disponibles

### 1. [Angular: Guía Completa de Programación Moderna](angular-programming-book/README.md)
Framework Angular moderno (v17/18/19+): componentes Standalone, Signals, Control Flow nativo, vistas diferibles, zoneless, micro frontends y PWAs.
- **19 capítulos** | `angular-programming-book/`

### 2. [Arquitectura Orientada a Eventos: Guía Completa](event-driven-architecture-programming-book/README.md)
Fundamentos teóricos y prácticos de EDA: eventos, comandos, mensajes, Kafka, RabbitMQ, NATS, DDD, Event Sourcing, CQRS, Sagas y observabilidad.
- **17 capítulos** | `event-driven-architecture-programming-book/`

### 3. [Docker: De Novato a Experto en Contenedores](docker-programming-book/README.md)
Domina Docker y el ecosistema de contenedores: imágenes, Dockerfile, volúmenes, redes, Compose, orquestación, CI/CD, seguridad, monitoreo y producción.
- **13 capítulos + 2 apéndices** | `docker-programming-book/`

### 4. [Git: La Guía Completa - De Principiante a Experto](git-programming-book/README.md)
Control de versiones con Git: ramas, remotos, rebase, cherry-pick, stash, tags, submódulos, hooks, internals, conflictos, reescritura de historia, workflows y CI/CD.
- **21 capítulos + 3 apéndices** | `git-programming-book/`

### 5. [Go: Guía Completa de Programación](go-programming-book/README.md)
Lenguaje Go desde cero: sintaxis, tipos, concurrencia, interfaces, generics, testing, patrones de diseño, arquitectura hexagonal, gRPC, desarrollo web y observabilidad.
- **20 capítulos** | `go-programming-book/`

### 6. [Java: De Novato a Experto](java-programming-book/README.md)
Programación en Java desde fundamentos hasta producción: POO, colecciones, excepciones, I/O, concurrencia, streams, lambdas, JDBC y buenas prácticas.
- **10 capítulos** | `java-programming-book/`

### 7. [Arquitectura de Software: De la Teoría a la Práctica](software-architecture-programming-book/README.md)
Guía definitiva para convertirse en arquitecto de software: fundamentos, principios SOLID, DDD, Clean/Hexagonal, resiliencia, seguridad, escalabilidad, cloud, contenedores, observabilidad y más.
- **36 capítulos + 2 apéndices** | `software-architecture-programming-book/`

### 8. [Node.js + TypeScript: Guía Completa de Programación](node-programming-book/README.md)
Desarrollo backend con Node.js y TypeScript: sintaxis, asincronía, módulos, testing, generics, patrones de diseño, arquitectura hexagonal y desarrollo web.
- **17 capítulos** | `node-programming-book/`

### 9. [React: Guía Completa de Programación Moderna](react-programming-book/README.md)
Desarrollo frontend con React moderno (v18/19+): Virtual DOM, JSX, Hooks, Context, State Management (Zustand/Redux), Suspense, Server Components, Routing y Testing.
- **15 capítulos** | `react-programming-book/`

### 10. [Bases de Datos NoSQL: Guía Completa de Programación y Diseño de Sistemas](nosql-databases-programming-book/README.md)
Desarrollo, modelado y escalabilidad con bases de datos no relacionales: Teorema de CAP, MongoDB, Amazon DynamoDB, Redis, Apache Cassandra, Neo4j, Single-Table Design y consistencia eventual.
- **12 capítulos + 1 apéndice** | `nosql-databases-programming-book/`

### 11. [Bases de Datos Relacionales y SQL: Diseño de Sistemas de Alto Rendimiento](sql-databases-programming-book/README.md)
Desarrollo, optimización y diseño de arquitecturas con bases de datos relacionales tradicionales: internals de indexación (B-Trees, GIN), el motor de optimización física, niveles de aislamiento transaccional MVCC, bloqueos, Explain Analyze, particionamiento, migraciones zero-downtime y seguridad RLS en PostgreSQL.
- **15 capítulos** | `sql-databases-programming-book/`

### 12. [El Libro de DevOps: Integración y Entrega Continua (CI/CD) de Alto Rendimiento](devops-programming-book/README.md)
Automatización, cultura y tuberías de entrega continua: Git Flow, GitHub Actions, GitLab CI/CD, Azure DevOps, análisis estático y seguridad de código con SonarQube y Snyk, Docker, Terraform, ArgoCD, Kubernetes y observabilidad.
- **15 capítulos** | `devops-programming-book/`
